# Stock footage

The ads play stock footage behind their text. A clip in this folder is named
after the slot it fills, and the next render picks it up. It can be any length,
any orientation and any format ffmpeg reads (`.mp4`, `.mov`, `.webm`, or a
`.jpg` for a still). The renderer crops it to fit, makes it black and white,
darkens it and pushes in slowly, so colour clips are fine. A slot with no clip
shows the plain dark background.
